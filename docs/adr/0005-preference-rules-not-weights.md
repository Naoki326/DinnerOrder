# 喜好学习零数值权重：冷藏期 + 反馈摘要

家人反馈对推荐的影响只有两种机制：点踩 → 冷藏期（默认 14 天、家规可配；任一本餐用餐者触发即生效，布尔不叠加），期内该菜不进整餐推荐与换菜候选，到期自动解除；点赞与快捷标签聚合成近 30 天反馈文本摘要，注入推荐 prompt 作软信号。不建任何数值模型——没有评分、没有时间衰减曲线、没有 embedding 相似度。

理由：家庭 4–5 人的反馈样本量撑不起权重拟合，调参换不来可感知的个性化收益；规则 + 摘要零调参、每一条影响都可解释（「这道菜为什么没出现——点踩冷藏中」）。此决议曾推翻早期「M1 反馈仅记录、不进推荐管线」的占位表述，钉死形态防止反复。被否决的备选：按家人 × 菜谱的评分权重与时间衰减（需调参、难解释、小样本过拟合）；口味 embedding 模型（黑盒、家用量级无收益）。与 ADR-0001 的「零数值权重」条款互为表里，本条把「喜好学习」这一个角落也封死。
