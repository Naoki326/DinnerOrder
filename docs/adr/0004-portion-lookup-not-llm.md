# 份量纯规则查表，LLM 不进数值路径

份量计算（每道菜为本餐用餐者生成的生重克数）走纯规则查表：菜品份量 = 菜谱成人份生重基准 × Σ用餐者折算系数 × 留量上浮（仅留量标记 ∧ 有效引用时计入）。折算系数按 WS/T 554—2017 分年龄 × 性别带量表内置（票 #6 一手转录），小孩按出生年月现算年龄自动分带；成人份基准是菜谱 schema 的必填字段，导入/转正时由 LLM 把「适量」重标为克数。运行时 LLM 完全不进数值路径——推荐输出仅菜谱 id（ADR-0001），份量一律由后端查表得出。

理由：可解释（每个克数都能回溯到表与系数）、离线可用（断网不影响已定菜单的量）、零调用成本、错了好查好改（改表即改全局）。被否决的备选：LLM 逐次计算份量（幻觉直接进锅里、不可解释、断网即瘫、每次花钱）；营养素级精确计算（官方成分平台许可未明，家常菜场景属伪精度）。与 ADR-0001 同族：LLM 的合法位置在「选择与搭配」与离线的「适量→克数」重标，不在运行时数值路径。
